# Доска задач

Учебный проект на React, TypeScript и Vite для темы условного рендеринга.

## Запуск

```bash
pnpm install
pnpm dev
```

## Что реализовано

- `Task` с полями `id`, `title` и `isCompleted`;
- `TaskBoard`, принимающий `tasks: Task[]` через props;
- отображение задач через `map()` с `key={task.id}`;
- отдельный `TaskItem` для каждой задачи;
- пустое состояние «Задач пока нет»;
- зачёркивание выполненных задач.
